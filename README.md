# PsyScripts
Lightweight dependency-free scripts: Tabs, ThemeSwitcher, HeaderMenu, CopyButton, ScrollReveal, Accordion, Modal, Toast, BackToTop, LazyImages, Dropdown, Tooltip, Counter, Carousel, FormValidation, ScrollSpy, StickyTOC, Marquee, ImageLightbox, Parallax, CookieBanner, Skeleton.

Demo: `index.html` (serve over HTTP, e.g. `npx serve`; translations live in `locales/*.json`).

## Icon fonts
`npm install && npm run icons` copies Font Awesome, Bootstrap Icons, Material Design Icons and Tabler Icons into `vendor/icons/`.

## Minified build
`npm run build` also regenerates `docs.html` (requires Python 3; skipped with a warning otherwise) and writes `dist/*.min.js`, `dist/tabs.min.css`, `dist/psyscripts.min.css` and `dist/psyscripts.bundle.min.js`.

## Quick start
```html
<link rel="stylesheet" href="dist/psyscripts.min.css">
<link rel="stylesheet" href="dist/tabs.min.css">
<script src="dist/psyscripts.bundle.min.js" defer></script>
```
