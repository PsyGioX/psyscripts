Документация

22 скрипта без зависимостей. Всё работает через data-атрибуты; JS API нужен только для особых случаев.

Подключение

Всё одним файлом или по отдельности (dist/<name>.min.js). Tabs требует tabs.min.css.

<link rel="stylesheet" href="dist/psyscripts.min.css">
<link rel="stylesheet" href="dist/tabs.min.css">
<script src="dist/psyscripts.bundle.min.js" defer></script>

Tabs

Доступные табы: стрелки, Home/End, roving tabindex.

АтрибутОписание
data-tabsкорневой контейнер
data-tabкнопка вкладки; aria-selected="true" — активная по умолчанию
data-panelпанель, порядок как у кнопок
<div data-tabs>
  <div role="tablist"><button data-tab>A</button><button data-tab>B</button></div>
  <div data-panel>…</div><div data-panel>…</div>
</div>

JS: PsyScripts.Tabs.init(root) — для динамического контента. Нужен tabs.min.css.

ThemeSwitcher

Светлая/тёмная тема, localStorage, prefers-color-scheme. Ставит data-theme на <html>.

АтрибутОписание
data-theme-toggleкнопка-переключатель (получает aria-pressed)
<button data-theme-toggle>◐</button>

JS: PsyScripts.Theme.set('dark'|'light'), .toggle()

HeaderMenu

Адаптивное бургер-меню (до 860px), Esc и клик вне закрывают.

АтрибутОписание
data-headerшапка
data-menu-toggleкнопка-бургер
data-menuконтейнер ссылок
<header data-header>
  <button data-menu-toggle aria-expanded="false">☰</button>
  <nav data-menu><a href="#a">A</a></nav>
</header>

JS: PsyScripts.HeaderMenu.close(header)

CopyButton

Копирование текста или содержимого элемента, запасной путь для HTTP.

АтрибутОписание
data-copyтекст для копирования
data-copy-targetCSS-селектор источника
data-copiedтекст кнопки после копирования
data-copy-toastпоказать Toast с этим текстом
<button data-copy="npm i psyscripts" data-copied="✓">Copy</button>

JS: PsyScripts.copy(text) → Promise

ScrollReveal

Появление при прокрутке, учитывает prefers-reduced-motion.

АтрибутОписание
data-revealвключить; значения left / right меняют направление
data-reveal-delayзадержка, мс
<div data-reveal="left" data-reveal-delay="100">…</div>

JS: PsyScripts.Reveal.init(root)

Accordion

Плавный аккордеон без max-height-хаков (grid-rows).

АтрибутОписание
data-accordionконтейнер; + data-single — один открытый
data-acc-itemэлемент; класс is-open — открыт
data-acc-triggerкнопка
data-acc-panelпанель, внутри один <div>
<div data-accordion data-single>
  <div data-acc-item>
    <button data-acc-trigger aria-expanded="false">Q</button>
    <div data-acc-panel><div>A</div></div>
  </div>
</div>

JS: Делегирование кликов: работает и для добавленных позже элементов.

Modal

Модалки на нативном <dialog>: Esc, фокус-ловушка, клик по фону.

АтрибутОписание
data-modal-open="id"открыть dialog по id
data-modal-closeзакрыть ближайший dialog
data-modalатрибут на самом <dialog>
<button data-modal-open="m">Open</button>
<dialog id="m" data-modal>…<button data-modal-close>×</button></dialog>

JS: PsyScripts.Modal.open(id), .close(dialog)

Toast

Уведомления, aria-live, закрываются по клику.

АтрибутОписание
data-toastтекст уведомления по клику
data-toast-typeinfo | success | error
<button data-toast="Saved" data-toast-type="success">Save</button>

JS: PsyScripts.Toast.show('Text',{type:'error',duration:4000})

BackToTop

Кнопка «Наверх», появляется после прокрутки.

АтрибутОписание
data-back-topсама кнопка

<button data-back-top aria-label="Top">↑</button>

JS: Плавный скролл отключается при reduced-motion.

data-counter-fromстарт

Carousel

Карусель на scroll-snap: стрелки, точки, клавиатура, автоплей.

АтрибутОписание
data-carouselкорень; data-autoplay="мс", data-multi — 2 слайда на широких
data-trackлента слайдов
data-prev / data-nextкнопки
data-dotsконтейнер точек (создаются сами)
<div data-carousel data-autoplay="5000">
  <div data-track><div>1</div><div>2</div></div>
  <button data-prev>‹</button><button data-next>›</button><div data-dots></div>
</div>

JS: PsyScripts.Carousel.init(root)

FormValidation

Нативный Constraint Validation API + ARIA, свои сообщения.

АтрибутОписание
data-validateна <form>; + data-ajax — вместо отправки событие psy:valid
data-fieldобёртка поля (необязательно)
data-errorместо для ошибки (создаётся само)
data-msg-required / -type / -min / -patternсвои тексты на поле
<form data-validate data-ajax>
  <div data-field><input type="email" name="email" required data-msg-required="Введите email"></div>
  <button>Send</button>
</form>

JS: form.addEventListener('psy:valid', …); PsyScripts.Form.validate(form)

ScrollSpy

Подсвечивает ссылку меню, чей раздел сейчас на экране.

АтрибутОписание
data-spyна <nav> или контейнере со ссылками #id
is-activeкласс активной ссылки (+ aria-current)
<nav data-spy><a href="#a">A</a><a href="#b">B</a></nav>

JS: PsyScripts.Spy.init()

StickyTOC

Оглавление из заголовков: id, список и подсветка раздела. Это оглавление слева — он сам.

АтрибутОписание
data-tocконтейнер
data-toc-sourceселектор области (по умолчанию main)
data-toc-levelsзаголовки, по умолчанию h2,h3
data-stickyприлипает при прокрутке
<aside data-toc data-toc-source="#post" data-toc-levels="h2" data-sticky></aside>

JS: PsyScripts.TOC.init()

АтрибутОписание

Parallax

Лёгкий параллакс, rAF, отключается при reduced-motion.

АтрибутОписание
data-parallaxкоэффициент, например 0.2 (отрицательный — в другую сторону)
<img data-parallax="0.2" src="bg.jpg" alt="">

JS: PsyScripts.Parallax.init()

CookieBanner

Баннер согласия; выбор хранится в localStorage.

АтрибутОписание
data-cookie-bannerсам баннер (изначально hidden)
data-cookie-accept / data-cookie-declineкнопки

</div>

JS: document.addEventListener('psy:cookie', e => e.detail.consent); PsyScripts.Cookie.get(), .reset()
