Документация

31 скрипт без зависимостей. Всё работает через data-атрибуты; JS API нужен только для особых случаев.

Подключение

Одной строкой, bundle + css или по отдельности (core.min.js + dist/<name>.min.js). Стили (включая Tabs и иконки) — в psyscripts.min.css. Путь и SRI-хэш каждого скрипта — в блоке «Подключение отдельно» его раздела и в разделе «Файлы и SRI».

<!-- 1. one line -->
<script src="dist/psyscripts.auto.min.js" defer></script>

<!-- 2. production: styles + bundle -->
<link rel="stylesheet" href="dist/psyscripts.min.css">
<script src="dist/psyscripts.bundle.min.js" defer></script>

<!-- 3. only what you need (core is required for the configuration API) -->
<link rel="stylesheet" href="dist/psyscripts.min.css">
<script src="dist/core.min.js" defer></script>
<script src="dist/tabs.min.js" defer></script>

Безопасность

PsyScripts — клиентская библиотека без зависимостей и без сетевых запросов (кроме загрузки файлов переводов с вашего же origin). Ниже — что она гарантирует и что остаётся на вашей стороне. Результаты аудита: SECURITY-AUDIT-2026-10-19.md в репозитории.

  • Весь текст из атрибутов, опций и строк переводов вставляется через textContent; HTML из переводов (data-i18n-html) проходит SafeHTML.
  • URL в Lightbox и LazyImages проверяются по белому списку схем (http, https, blob:, data:image); javascript: и data:text/html отбрасываются.
  • Слияние настроек защищено от prototype pollution; значения design-токенов не могут выйти за пределы CSS-объявления.
  • Неверный селектор в data-copy-target, data-match, data-toc-source не ломает страницу.
  • Нет eval, new Function, document.write, inline-обработчиков и внешних хостов: подходит строгая CSP и Trusted Types.

Рекомендуемые заголовки. Эта CSP применяется на сайте проекта (vercel.json): в разметке нет inline-стилей, inline-скриптов и обработчиков (это проверяют тесты), а стили добавляются через adoptedStyleSheets, поэтому 'unsafe-inline' не нужен. Trusted Types включены в режиме Report-Only: откройте сайт, убедитесь, что в консоли нет нарушений, и переведите директиву в Content-Security-Policy.

Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self'; manifest-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'; upgrade-insecure-requests
Content-Security-Policy-Report-Only: require-trusted-types-for 'script'; trusted-types psyscripts
Strict-Transport-Security: max-age=63072000; includeSubDomains
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), browsing-topics=()
Cross-Origin-Opener-Policy: same-origin

Если нужен nonce. В браузерах без adoptedStyleSheets библиотека добавляет <style>; передайте nonce так: <meta name="psy-nonce" content="…">.

Что остаётся на вашей стороне:

  • Никогда не пишите чужие данные в innerHTML: используйте textContent или PsyScripts.Sanitize.set(el, html).
  • CookieBanner хранит только факт согласия (localStorage) и не блокирует трекеры сам: проверяйте PsyScripts.Cookie.has('analytics') перед их загрузкой.
  • localStorage читается любым скриптом на origin: не храните там секреты (библиотека хранит тему, язык, согласие, токены и id команд).
  • Всегда отдавайте сайт по HTTPS: Clipboard API и Trusted Types работают только в защищённом контексте.
  • Подключайте скрипты с SRI (см. раздел «Файлы и SRI») и обновляйте версию осознанно.

Нашли уязвимость? Напишите по адресу из /.well-known/security.txt или в приватный Security Advisory на GitHub — не открывайте публичный issue.

FAQ и решение проблем

  • Скрипт не работает. Проверьте, что core.min.js подключён раньше (или используйте bundle) и что в консоли нет нарушений CSP.
  • Контент добавляется позже. Вызовите PsyScripts.init(root) или включите PsyScripts.observe() / data-psy-observe на <html>.
  • Мигает тема. Подключите theme-switcher в <head> без defer.
  • Нет стилей при подключении по отдельности. Добавьте dist/psyscripts.min.css (в нём и Tabs, и иконки).
  • CSP блокирует стили. Не добавляйте 'unsafe-inline': используйте актуальную версию (adoptedStyleSheets) или передайте nonce через meta[name=psy-nonce].
  • data-i18n-html показывает теги как текст. Подключите safe-html.min.js — без него HTML намеренно не вставляется.
  • Переводы не грузятся с CDN. По умолчанию разрешён только свой origin; включите data-i18n-cross-origin осознанно.
